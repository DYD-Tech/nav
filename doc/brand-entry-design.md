# 品牌主站入口

- 目的：说明 Prism 是懂一点实验室的产品，并提供直达个人品牌主站的入口。
- 桌面：侧栏底部用细分隔线划出辅助区，左侧语言图标，右侧品牌文字与小外链箭头。同一行对齐，12px 中灰文字，悬停加深、键盘焦点清晰。
- 手机：沿用右上角辅助区，语言图标与 11px 品牌文字并排，不新增栏位；检查中文品牌与左侧 Prism 不重叠。
- 内容：中文“懂一点实验室”，英文“DYD Lab.”；目标 `https://dydlab.com/`。新标签打开保留导航页位置，无障碍名称说明主站与新标签行为，字段位于 JSON 的 `studio`。
- 页底建议（未实现）：资源费用与授权以官方说明为准的简短说明，以及失效链接/资源推荐反馈入口。反馈去向未指定，不添加空链接或虚构备案、联系方式。
- 对标：[MDN a · Accessibility / Security and privacy](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/a) 的有意义链接名称与新标签提示；参考 [GitHub 首页 Footer](https://github.com/) 将品牌归属与辅助操作集中呈现的层级。本项目只采用单行归属入口，不扩充多列页脚。
