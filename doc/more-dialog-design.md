# 「更多」弹窗设计

范围：所有资源小标题共用的同一个弹窗，按 `page` + `group` 绑定数据；不是某个栏目专用。两类全部展开，每项显示名称和一句帮助选择的简介；首页仍只显示名称。

- 入口：所有资源小标题都可点击，原位置保留标题字号与颜色，以细下划线、悬停和焦点样式提示交互；不在网站列表末尾重复放“更多”。小标题按钮支持 Enter、空格；关闭后焦点返回原小标题。
- 空状态：没有对应补充数据或所有分类条目为空时，弹窗只显示“无 / None”，不生成空分类；弹窗清空上次内容，避免跨栏目串内容。
- 层级：标题“更多 / More”与关闭按钮 → 付费优质平台 → 分隔线 → 免费 · 待甄选。每个网站的简介说明其特点和条件，不再显示分组说明段落。
- 尺寸：桌面最大宽 640px，为简介留出行宽；手机左右留 16px；高度由内容决定，最多 80dvh，超出时仅弹窗内容滚动。
- 网格：桌面组内两列，列间距 24px；手机单列。名称 14px、简介 12px，间距 5px；简介完整换行，不截断。
- 空间：桌面内边距 28px，手机 20px；组间 20px，条目间 12px；无嵌套卡片或徽章，整项可点击。
- 背景：保留滚动条占位，再锁定背景滚动。关闭后恢复滚动位置与触发按钮焦点；支持关闭按钮、Esc、遮罩。
- 双语：中文“免费 · 待甄选”，英文“Free · Not yet curated”；说明与标题来自资源 JSON。检查中英文桌面/手机、短屏及大量条目的滚动。

交互对标：[WAI-ARIA APG · Button Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/button/) 的 Keyboard Interaction / Roles：用按钮打开弹窗，支持 Enter、空格与焦点恢复；采用 [MDN dialog · Examples](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/dialog#examples) 的原生 `showModal()` 实例方式。保留本项目通用弹窗标题“更多 / More”，按钮无障碍名称包含所属栏目，避免重复入口造成歧义。
