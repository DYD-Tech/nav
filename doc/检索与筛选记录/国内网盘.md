## 整页拆分与命名（本页各栏的由来）

改动前"网盘"页只有 **国内网盘 / 国际网盘** 两栏，只按地域分，不含任何用途信息；而页面导语写的是"存储与分享"，实际一个传输服务都没收。先改为四栏：**国内网盘 / Drives in China**、**国际网盘 / Global drives**、**加密与隐私云盘 / Encrypted & private drives**、**大文件传输 / Large file transfer**；同日再补第五栏 **WebDAV 网盘 / WebDAV drives**（判据、取证与移栏清单见 `WebDAV网盘.md`）。

地域和用途混排是有意为之，不是疏漏：

- 国内与国际放在同一维度比较，是因为它们的差别本来就集中在访问条件、注册门槛与限速政策上，同类内部可比。
- 加密云盘和传输工具是不同用途。若把它们塞进"国际网盘"，会出现"Dropbox 和 Icedrive 怎么比"这种没有意义的问题。
- 与加密栏的边界：MEGA 虽有端到端加密，仍留在国际网盘——它是综合网盘，加密只是功能之一；Proton Drive、Filen 这类把隐私当核心卖点的才进加密栏。
- 自建网盘程序（Cloudreve、OpenList 等）需要自己准备服务器，按规则不进首页，只进对应弹窗的"免费 · 待甄选"：中文社区开发的算国内网盘；Nextcloud、Seafile 有官方 WebDAV 文档，改挂到 WebDAV 网盘栏的弹窗（见 `WebDAV网盘.md`）。
- 与效率与协作页的边界：办公套件自带的存储（飞书、Google Workspace）不在本页重复收。2026-10-28 隐私与安全页删除后，加密通讯与邮箱类服务不再收录，本页仍只收存文件的网盘。
