# 对象存储（`page=dev`，`group=对象存储`）

最后更新：2026-10-28。第 1 轮：中英双渠道发现 + 官方定价页与免费额度页逐条核实。

当前收录：**首页 5 条** — Cloudflare R2、Backblaze B2、Tigris、Upstash Blob、Oracle Cloud Object Storage；**更多 · 付费优质平台 3 条** — Amazon S3、Wasabi、Hetzner Object Storage；**更多 · 免费 · 待甄选 6 条** — 七牛云对象存储 Kodo、京东云对象存储 OSS、Google Cloud Storage、Neon Object Storage、Filebase、MinIO AIStor Free。

本栏目的取舍重点不是存储量，而是**出网流量怎么算**。"免费空间大但出网按 GB 收费"的服务放首页会让小项目直接被账单击中，所以首页五条的共同点是出网免费或有明确的免费上限。
