# 大文件传输

栏目位置：网盘 → 大文件传输（首页 5 项，弹窗 3 项，付费类为空）。核对日期 **2026-10-28**。

## 为什么加这一栏

"网盘"页导语本来就写着"存储与分享 / Storage and sharing"，但改动前一个传输服务都没收，只有一堆"存起来慢慢用"的网盘。传输工具与网盘的区别在于**默认会过期**：网盘买的是长期空间，传输买的是"把这一个文件送到别人手上"。两者放一起比没有意义，所以单独成栏。

与"实用工具 → 文件与 PDF"的分界：那一栏处理格式转换、压缩等，本栏只管把文件送出去。

## 更多 · 免费 · 待甄选

- **Wormhole**：`wormhole.app`："文件最大可达 10 GB"、"Wormhole 让你能以**端到端加密**和**自动过期链接**的方式分享文件"（正文 254 字）。放待甄选：页面没有出现 free 字样，长期免费与否未证实。
- **Tmp.Ninja**：`tmp.ninja`："**Free temporary (48h) 10GB file hoster.**"、"We comply strictly with DMCA takedowns"。放待甄选：48 小时即失效、单文件 10GB，只适合临时中转；运营主体与长期承诺未核实。
- **send**：`github.com/timvisee/send`："Simple, private file sharing. Mirror of https://gitlab.com/timvisee/send"、"Instances — Find a list of public instances"。Firefox Send 停服后的社区延续版，自托管即是自己的传输站；公共实例质量参差，所以只进待甄选。

## 不收 / 待核实

- **Send Anywhere**：`send-anywhere.com` 与 `/pricing` 正文 89 字，只有 "Your browser is not supported. Please update your browser."，免费额度（历史上传说是每月次数）本轮无法取证，暂不收录。
- **tem.p2p.de（OBFS）**：`SSL: TLSV1_UNRECOGNIZED_NAME`，握手就失败，不收。

- **奶牛快传的注册要求与保存期**：官方页只取到标题，具体条款待浏览器渲染后补记。
