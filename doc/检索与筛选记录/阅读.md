栏目位置：**阅读**（大分类，紧接"音乐"之后、"数据"之前）→ 图书与档案 / 论文与学术 / 课程与教材 / 百科与思想。首页 24 项（6 / 5 / 8 / 5），4 个"更多"弹窗共 40 项（付费优质平台 3 项、免费 · 待甄选 37 项）。核对日期 **2026-10-28**，下面的引文全部来自本轮实际抓取（urllib 直抓、浏览器读 `innerText`，或 Wayback 原始快照并记时间戳）。

## 页名为什么改成"阅读"

原名"书与知识"是两个抽象名词并列，既没说清里面装的是什么，也和其它大分类的两字命名（视频、音乐、网盘、开发）不齐。用户定名**阅读 / Reading**。页面里四个小分类仍然是具体的"图书与档案 / 论文与学术 / 课程与教材 / 百科与思想"，所以只改大分类名，不动小分类名与 `groupLabels`——改名会带来文档、记录与语言切换的连带修改，小分类名本身没有毛病，不值得动。

`eyebrow`、`headline`、`description` 一并换成"静下心来 / 从一本书，到一门学问。"这套说法。**注意**：`app.js` 的 `renderResource()` 只用 `title`，`eyebrow`/`headline`/`description` 只在首页（`renderHome()`）渲染，所以这三项对本页是数据一致性维护，界面上看不到——改完在浏览器里确认过：面板标题中英文分别是"阅读 / Reading"，正文只有小分类与名称链接。

## 检索方法

中英文各一轮开放式检索，先列候选再逐条取证，已知名单只用来对照。候选清单落在临时文件（58 个），逐个抓官方首页、定价页、关于页或帮助页。

三种取不到正文的情形，处理方式不同：

- **Cloudflare/Anubis 挡爬虫**（urllib 返回 403，或 200 但正文是 `Client Challenge`、`Making sure you're not a bot!`）：改用浏览器读 `document.body.innerText`。DOAJ 连浏览器也停在 `Just a moment...`，就转 Wayback 原始快照，并把快照时间戳写进记录（DOAJ 20260831162116、PubMed 20261020235448、FutureLearn 20261016003749）。
- **脚本渲染，去掉脚本只剩几十字**（OpenStax、Europeana、CNKI、识典古籍）：同样用浏览器复读；仍然读不到条款的，条目里写"本轮未取证"，不替它编价格或额度。
- **Wayback 也吃 429**（HathiTrust、JSTOR、SSRN、PhilPapers、BASE、国学大师、Class Central 首轮、OpenLearn 首轮）：不当作站点已死，只当作"本轮没取证"。Class Central 与 OpenLearn 后来在浏览器里读到了第一方文案，才写进弹窗。
