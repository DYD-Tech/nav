# 综合工具箱

栏目位置：实用工具 → 综合工具箱（首页 3 项，弹窗 2 项：付费优质平台 0 项、免费 · 待甄选 2 项）。核对日期 **2026-10-28**，全部证据为本轮实际抓取。

## 为什么新立这一栏，以及为什么把二维码放进来

两条线索汇到一起：

- **中文渠道查出来一批"整站就是工具箱"的站点。** 帮小忙（`tool.browser.qq.com`）、即时工具（`67tool.com`）、在线工具集（`xtechtools.com`）、以及 iamwawa 一类时钟换算站。它们的价值不在单个功能做得多深，而在"一个页面里什么都有"，把帮小忙拆进图片、PDF、换算三栏反而看不出它存在的意义，所以单立一栏收纳这类聚合入口。
- **二维码只有两家值得收，撑不起独立一栏。** QRCode Monkey 与 goqr.me 都是"生成一个静态码"这一件事，为它们开一栏会让实用工具页多出一个两项的窄栏目；这类需求本身也是"日常零散小事"，与工具箱同源，因此并进本栏，栏目名叫"综合工具箱"（en: Tool Collections）而不是"二维码"。

顺带处理一处历史不符：实用工具页的 `description` 原文写着"文档、图片、文本、**翻译**、地图与日常网络工具"，但站内从来没有翻译与地图条目——DeepL 在 AI 页（链接序号 36），OpenStreetMap 在数据页的"科学与地图"（序号 231），Radio Garden 在影音页（序号 89）。本轮把 description 改成与六个小栏目一致的说法，**没有**为此新增翻译或地图条目：同一产品不在两个大分类重复收录。

> **2026-10-28 同日更新**："影音页"已拆成**视频**与**音乐**两个大分类，上面提到的 Radio Garden 现在在 **音乐 → 播客与电台** 的"更多 · 免费 · 待甄选"里，链接序号也随本轮重写变化，只作历史线索看。数据页同日改名"数据 / Data"并重分栏目，原来的"科学与地图"已删除，OpenStreetMap 现在在 **数据 → 地图与地理**（详见 `数据.md`）。
