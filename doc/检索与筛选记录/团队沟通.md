# 团队沟通

栏目位置：效率与协作 → 团队沟通（首页 4 项，弹窗 3 项）。核对日期 **2026-10-28**。

## 拆分与命名

原"日程与沟通"把 Slack 和 Google Calendar 混在一栏。拆开之后这一栏只放"团队说话的地方"：频道式 IM、语音社区、企业协作套件。命名 **团队沟通 / Team Messaging**。

边界：主打隐私的即时通讯（Signal、Proton Mail 等）留在隐私页，不重复收；视频会议单列一栏（见"视频会议"记录），但飞书这类"IM＋文档＋会议"捆绑的套件按其主要入口（团队沟通）归类，文档与会议能力写进它的简介。

## 更多 · 付费优质平台

无。企业 IM 的付费能力已经体现在 Slack/Teams/飞书的付费档里；本轮没有"只收订阅但值得推荐"的独立候选。

## 更多 · 免费 · 待甄选

- **Zulip**：`zulip.com/plans/`：云端 "Free — **10,000 messages of search history**, File storage up to 5 GB total, Complete team chat solution"，自托管一侧写 "Free — Complete team chat solution, with all Zulip features included"，并说明 "Many organizations are eligible for a free Standard plan"（开源项目、学术与非营利）。放待甄选：主题串（topic-based）模式与常见 IM 差别大，需要用户改变使用习惯；免费档搜索历史有限。
- **Mattermost**：`mattermost.com/pricing/` 出现 "Get started for free with a **limited-use edition** of Enterprise Advanced for technical evaluation" 与 "Organizations using **Mattermost Free** to evaluate a future purchase of Mattermost Enterprise…"，支持一侧提到 "free forums and documentation"。放待甄选：免费面向"评估/自托管"，不是给普通团队长期使用的托管服务；官网正文混有大量前端脚本注释，抓取噪声大。
- **Rocket.Chat**：`rocket.chat` 首页："Deploy a **free self-managed workspace** to try Rocket.Chat. Core collaboration and security features…"。放待甄选：免费的是自托管部署，需要自己准备服务器与运维；官方托管版走订阅。
