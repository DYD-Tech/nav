# 数据

栏目位置：**数据**（大分类，紧接"阅读"之后，是最后一张面板）→ 开放数据 / 地图与地理 / 天气与气候 / 新闻与趋势。首页 21 项（8 / 4 / 4 / 5），4 个"更多"弹窗共 20 项（付费优质平台 2 项、免费 · 待甄选 18 项）。核对日期 **2026-10-28**，下面的引文全部来自本轮实际抓取（urllib 直抓、浏览器读 `document.body.innerText`，或 Wayback 原始快照并记时间戳）。

## 页名为什么改成"数据"，栏目为什么重分

- **页名**：原名"数据与世界 / Data & World"里"与世界"是空的修饰词——它既不说明里面装的是什么，也和其余大分类的两字命名（视频、音乐、网盘、开发、阅读）不齐。用户定名**数据 / Data**，`eyebrow`（理解真实世界）、`headline`（让事实更清晰）保留，`description` 换成与四个小栏目对齐的"统计、地图、科学观测与趋势数据的公开入口。"**注意**：`app.js` 的 `renderResource()` 只用 `title`，`eyebrow`/`headline`/`description` 只在首页渲染，所以这三项对本页是数据一致性维护，界面上看不到。
- **旧结构的问题**：本轮之前这一页只有三个小栏目，其中"科学与地图"把地图、卫星影像与气候观测混在一栏，而且**一个"更多"弹窗都没有**——小标题点下去全是"无 / None"。原首页条目里 NASA 指向的是机构门户而不是数据入口，Eurostat、UN Data、Google Trends/News 等也只挂着名称，没有一句可核对的条件说明。
- **重分后的四栏按数据来源划分**：官方统计（开放数据）、地理底图与影像（地图与地理）、气象与气候观测（天气与气候）、公众兴趣与传播（新闻与趋势）。"科学与地图"这个键从 `groupLabels` 直接删除，不留兼容。天气与气候之所以单独成栏：中文渠道有 `data.cma.cn`，英文侧取到 ECMWF、CDS、NCEI、Met Office、NWS、EUMETSAT 六家机构数据入口，首页加弹窗够一栏，而且它们与"地图与地理"（底图与影像 vs 观测时间序列）不是同一用途。

## 检索方法

中英文各一轮开放式检索，先列候选再逐条取证，已知名单只用来对照。候选分三批用 urllib 铺开（`dv_probe1/2/3`，含状态码、跳转后地址与去标签正文字数），补抓一批定价与目录页（`dv_probe5`），再单独取关键词原句做证据（`dv_evid`、`dv_price`）。

三种取不到正文的情形，处理方式不同：

- **脚本渲染，去掉脚本只剩几十字**（`data.un.org` 89 字、`gapminder.org/tools/` 0 字、NASA Worldview 14 字、`data.cma.cn` 7 字、`index.baidu.com` 30 字、Google Trends/News 抓到几十万字节却是样式与脚本）：改用浏览器读 `document.body.innerText`。
- **境内站点对外网地址拦截**（`tianditu.gov.cn`、`map.tianditu.gov.cn`、`data.stats.gov.cn`）：urllib 与浏览器都拿到 **418**"your request has been intercepted because it appears to be an attack"或 **403** `reason:UrlACL`，退到 Wayback 原始快照（`id_`），天地图用快照 **20261005062425** 取到首页标题"国家地理信息公共服务平台 天地图"。**拦截这件事本身写进了条目条件**，不说它不可用。
- **Wayback 也吃 429**（resdc.cn、`tianditu.cn` 旧域名）：只当"本轮没取证"，不给站点下死活结论。

## 跨页归属与边界

- **预报与可视化 vs 原始数据**：Windy、Yr、Open-Meteo、timeanddate 留在**实用工具 → 天气与时间**（面向"看天气、换算时间"的日常用途）；本页的天气与气候栏只放机构级观测与再分析数据入口（ECMWF、CDS、NCEI、中国气象数据网、Met Office、NWS、EUMETSAT）。同一个站点不双挂。
- **NASA**：原首页条目 `nasa.gov` 是任务与新闻门户（正文 10252 字，导航 News & Events / Multimedia），不能当数据入口。本轮换成 `worldview.earthdata.nasa.gov`（可视化，进首页）与 `earthdata.nasa.gov`（数据门户，进弹窗）。`apod.nasa.gov` 已跳 `science.nasa.gov/apod`，属每日一图而非数据平台，不收。
- **开发者向的地理/数据 API**：`developer.amap.com`（高德开放平台，正文自述"高德地图API 控制台 … 搜索定位 … 地理围栏"）与天地图的开放平台密钥都是**开发页 → API 与数据**的用途，本页只收面向公众的数据入口，不重复。
- **科学数据中心类**：`geodata.cn`、`gscloud.cn` 归本页"地图与地理"；论文与代码库仍在**阅读**与**开发**页。Hugging Face、Kaggle 这类开发者数据集平台不在本页重复挂（Kaggle 本轮也被 reCAPTCHA 挡住，见下）。
- **被删除的"隐私与安全"页**：其条目没有并入本页——本页只收统计、地图、气象与趋势数据，不含浏览器、通信与密码类工具。
