# 网站托管（`page=dev`，`group=网站托管`）

最后更新：2026-10-27。本轮做两件事：付费名单补价格依据，首页条目只做「免费方案今天还在不在」的二值复核。

收录口径（用户 2026-10-27 定）：首页只要求**核心用途至今仍提供免费方案**；额度、限速、休眠这类随时会变的数字**不做实时追踪，也不写进首页**，由读者自己上官网看。首页本来就只渲染名称（`app.js` 的 `card()` 只取 `name`）。

当前收录：**首页 9 条** — Vercel、Netlify、Cloudflare、GitHub Pages、Firebase、Render、Koyeb、Deno Deploy、PythonAnywhere；**更多 · 付费优质平台 5 条** — Railway、Fly.io、Heroku、Hostinger、DreamHost；**更多 · 免费 · 待甄选 2 条** — Neocities、Qoddi。

## 名单变动与理由

- **Fly.io 移出首页、进付费名单**：官方文档明写新组织无免费层，留首页等于给错预期。
- **AWS Amplify 移出付费名单**：$15/月/应用之上还叠六项按量超额，且必须先有 AWS 账号，是这张表里最容易产生意外账单的一个，与「付费优质平台＝可靠且可预算」的定位冲突。网址与来源保留在这里，不再占用名单。
- **Heroku 保留但重写**：Eco $5 看着便宜，实际是共享池化算力、不能常驻，常驻要 Standard $25 起；同资源比 Fly.io/Render 贵一档。之所以还留着，是因为它的账单可预测、且是老牌参考点。
- **新增 Hostinger 与 DreamHost**：这两条是「不写代码的人真正会买」的共享主机，且各自的最大坑都能用官方页一句话说清（Hostinger 要预付 48 个月、续费 $10.99；DreamHost 有约 4 万月访问软上限）。
- **Qoddi 进免费 · 待甄选**：免费 3 个静态站且称不限流量，但厂商规模小、条款未能全部读到，按规则归「待甄选」而非首页。
- **Cloudflare Workers / Koyeb / Render / Vercel / Netlify 不进付费名单**：同厂商同产品已在首页，规则禁止重复收录；它们的价格对照只留在本文件。

## 中文读者专属（2026-10-27 中文渠道检索）

- **默认域名在大陆不保证可访问**，这是英文横评不会写的一条。**Vercel 官方 KB（2025-11-03）自己承认**：中国网络管控可能阻断或限速 `.vercel.app` 等境外域名，官方无大陆节点、不提供 ICP 支持（[原文](https://vercel.com/kb/guide/accessing-vercel-hosted-sites-from-mainland-china)）。
- **Cloudflare 免费档没有大陆可达承诺**；大陆加速属于与京东云合作的「中国网络」，面向企业（[官方页](https://www.cloudflare.com/zh-cn/application-services/products/china-network/)）。社区两起一手求助（2025-01 河北、2026-04-30）说连自定义域名也会超时，**根因（IP 段还是 SNI）未获官方确认，属推断**。
- 历史事件：`workers.dev` 在 2022-10-04 遭 DNS 污染（社区记录，[腾讯云开发者社区](https://cloud.tencent.com/developer/article/2133923)）；2024-12 有安全厂商报告 `pages.dev`/`workers.dev` 被大量用于钓鱼（[Fortra](https://www.fortra.com/blog/cloudflare-pages-workers-domains-increasingly-abused-for-phishing)），**这解释了免费共享域名为什么更易被阻断，但因果仍是推断**。
- **Netlify 被墙的具体时间与官方说明：未查到**（试过「Netlify 被墙 时间」「pages.dev 污染」等中文关键词）。
- 中文渠道的所谓「官方购买教程」几乎全是返利站冒充：`bandwagonhost.net`、`vultrcn.com`、`racknerd.cc`、`idcspy.com`、`netcupzw.com` 等都不是厂商域名，还有一批 SEO 用的 GitHub 假教程仓库。**本轮已实测到其中一处与官方直接冲突**：`vpspaihang.com` 2026-10-03 的文章说 DigitalOcean 不支持支付宝，而 DO 官方文档（Last verified 2026-07-30）的付款方式里就列着 Alipay。这些站点一律不进任何栏目，只当线索。
