# 检索与筛选记录

这个目录存放**"为什么收它、为什么不收它"的过程记录**：查过哪些渠道、拿到什么证据、当时怎么判断、还有什么没核实。

和另外两份文档的分工：

- `doc/more-dialog-design.md`：弹窗与资源区的**界面与交互规格**，不讲内容取舍。
- `doc/SPEC.md`：产品范围与长期约定。
- 本目录：一次一次的具体调查，供复核和续工时接着用。

## 文件命名

一个资源小栏目一个文件，用中文栏目名，例如 `域名.md`、`代码托管.md`。栏目改名时文件跟着改名，不保留旧文件。

## 每条记录必须有的字段

| 字段 | 写什么 |
| --- | --- |
| 条目名 | 与 `data/resources.json` 里的 `name` 一致 |
| 结论 | 首页 / 更多·付费优质平台 / 更多·免费·待甄选 / 不收 / 待核实 |
| 证据 | 官方页、官方文档、官方条款或官方仓库的具体 URL；二手教程只能当线索，不能作为结论依据 |
| 证据日期 | 实际核对当天日期；页面被反爬挡住而改用存档时，写清存档快照时间点 |
| 条件 | 额度、续费或到期与回收规则、审核方式、地区与注册限制、需要额外付费的部分 |
| 主体 | 运营方身份与辖区；涉及域名时写清 ICANN 认证注册商或注册商记名 |
| 风险 | 滥用口碑、历史泄露或关停、单人运营、条款可单方变更、转出即失效等 |

## 分类口径（与 `AGENTS.md` 一致）

- **首页**：核心用途有可持续免费方案，且质量与可信度足够作为默认推荐。
- **更多 · 付费优质平台**：收费但成熟、值得推荐。
- **更多 · 免费 · 待甄选**：免费但不宜作默认推荐——适用范围窄、需自建、有审核门槛，或服务情况尚待确认。这里不是"低质量"。
- **不收**：已停免费、无法核实、或根本不提供该类资源（例如只做 DNS 托管、不发域名）。
- **待核实**：有线索但没有官方证据。必须写清卡在哪一步，以及下次该查什么。

## 更新方式

按轮次追加，不覆盖旧判断。旧判断被推翻时保留原文并标注"某日被某条证据推翻"，因为这正是下次复核要看的路径。
