当前收录：**首页 7 条** — GitHub、GitLab、Bitbucket、Azure Repos、Gitee 码云、Codeberg、SourceForge；**更多 · 付费优质平台 2 条** — Origin、Assembla；**更多 · 免费 · 待甄选 4 条** — Gitea、Savannah、GitGud、Framagit。

## 判断记录

| 条目 | 结论 | 依据 | 证据 |
| --- | --- | --- | --- |
| GitHub、GitLab、Bitbucket、Codeberg、SourceForge、Gitee | 首页 | 均提供可用的免费托管 | [Codeberg FAQ](https://docs.codeberg.org/getting-started/faq/)、[SourceForge 功能](https://sourceforge.net/create/) |
| Azure Repos | 首页 | Azure DevOps 内的私有代码托管，小团队免费 | [Azure DevOps 定价](https://azure.microsoft.com/en-us/pricing/details/devops/azure-devops-services/) |
| Gitea | 待甄选 | 免费但**需自建**，本身不含免费云托管，容易被误当成免费服务 | [Gitea 定价](https://about.gitea.com/pricing/) |
| Savannah | 待甄选 | 免费但限符合许可与依赖要求、并通过项目审核的自由软件项目 | [Savannah 项目审核](https://savannah.gnu.org/maintenance/HowToGetYourProjectApprovedQuickly/) |
| GitGud、Framagit | 待甄选 | 社区运营的免费 GitLab 实例，分别存在地区访问限制与注册条件、实例配额 | [GitGud](https://about.gitgud.io/)、[Framagit 实例配置](https://framagit.org/help/instance_configuration) |
| Origin | 更多·付费 | Cursor 的代码托管，需付费方案 | [Origin 文档](https://cursor.com/docs/origin) |
| Assembla | 更多·付费 | 商业 Git/SVN 托管，只有试用期内免费 | [Assembla 定价](https://get.assembla.com/pricing/) |

两条口径记在这里，防止以后被改回去：

- Codeberg 与 SourceForge 偏向开源项目，这属于定位差异，**不作为质量降级理由**；不因平台小众就往后放，也不因大厂出品就忽略收费条件。
- 免费开源软件不等于免费云服务：Gitea 就是这一类，简介必须写清需要自备服务器和维护。
