# FreeNav / 巡航：产品与开发规格

## 目标

做一个适合设为浏览器主页的静态网站：在一个安静、快速的界面中完成多站搜索和常用网站访问，并浏览按主题整理的合法免费资源平台。

## 核心体验

- 首页：一句欢迎语、搜索框、可编辑的主页搜索引擎和常用入口。
- 搜索：在设置中勾选需要显示的引擎；第一项是输入框右侧的默认搜索，其余引擎以独立按钮排列在下方。每次搜索只打开一个结果页。
- 资源页：按「网页 AI、书与知识、影像与声音、创作素材、开发与 API、效率与协作、实用工具、数据与世界、隐私与安全」分页面展示；每项是提供资源的合法平台，而非具体盗版内容。
- 语言：含中文偏好的浏览器使用中文；其他浏览器使用英文。侧栏的语言下拉菜单支持即时手动覆盖并在本机记住；语言列表和界面翻译均由数据定义，新增语言无需改 UI 结构；用户自建的编排名称保持用户输入。
- 内容和 UI 分离：引擎与链接存放在 JSON；用户选择的主页引擎存于 localStorage。

## 视觉与交互

- 气质：克制、明亮、圆润、留白充足；参考苹果产品页的信息层级，但不仿制品牌资产。
- 桌面端用固定侧栏与内容画布；移动端侧栏折叠为横向导航。
- 首屏只展示必要操作。弹窗用于编辑编排，避免主页拥挤。
- 所有外链新窗口打开，卡片显示用途与标签；键盘 Enter 可搜索。

## 技术与边界

- 原生 HTML/CSS/JavaScript，无构建步骤，兼容 GitHub Pages。
- 仅收录合法服务的官方或可信入口；数据结构包含中英文分类、描述、标签与 URL。免费可能是永久免费、开源、公共领域或有免费层，具体以站点条款为准。
- 不收集账号或搜索词；仅使用本地存储保存用户的编排选择。
