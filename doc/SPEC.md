# Prism 棱镜：产品与开发规格

## 目标

从不断增长的信息与资源中精选合法、实用的免费平台，减少用户寻找和甄别的成本，适合作为浏览器主页。

## 页面与内容

- 搜索区独立布局；资源在同一页面向下展开，侧栏跳转到相应分类。
- 每个资源大分类一张面板，内部按小分类排列网站名称，不显示逐站描述、图标卡片或 Tab。同一行内的名称顶部对齐：长名称换行使整行变高时，相邻短名称的首行仍与它第一行齐平。
- 首页只放免费精选；每个小标题可点击，打开对应“更多”弹窗，不另放入口按钮。有补充内容时仅展示该栏目的“付费优质平台”和“免费 · 待甄选”两类；无内容时显示“无 / None”。
- 弹窗标题通用为“更多 / More”，每个网站显示名称和一句帮助选择的简介，不显示分组说明段落。
- 收录平台而非具体文件；免费方案、开源授权和素材许可须区分，筛选标准见 `AGENTS.md`。

## 交互与语言

- 有搜索词时点击引擎打开该引擎结果；无搜索词时打开对应网站。一次打开一个标签，输入不清空；不提供搜索策略或搜索编辑。
- 外链新标签打开；弹窗支持关闭按钮、Esc、遮罩关闭，保留背景布局、滚动位置与触发按钮焦点。
- 支持中文、英文；自动匹配浏览器语言，不支持的语言默认英文，用户手动选择保存在本机。所有新增界面与文案同步适配两种语言。
- 侧栏底部固定显示语言图标，不在页面上写出当前语言；点图标弹出语言列表，选一项立即切换整站文案并关闭列表，当前语言只在列表内用一个勾标记。点别处、按 Esc 或选中都关闭列表，关闭后焦点回到图标。“选择语言 / Choose language”只给读屏软件。
- 产品归属懂一点实验室 / DYD Lab.：`data/resources.json` 的 `studio` 维护主站网址、双语名称与访问说明。主站链接和语言图标并排放在侧栏底部，手机沿用右上工具区；新标签打开 `https://dydlab.com/`。
- 桌面固定侧栏、手机横向导航；资源布局自适应。弹窗最大宽 640px、高 80dvh，桌面双列、手机单列，超高仅滚动内部内容。

## 技术与维护

- 原生 HTML/CSS/JavaScript，无构建依赖，可部署 GitHub Pages；本地预览须用 HTTP 服务读取 JSON。
- `data/resources.json` 管理搜索引擎、分类、首页链接、弹窗条目与双语内容；用户语言偏好保存在 localStorage，不收集搜索词。
- 访问统计用 Cloudflare Web Analytics，脚本手动写在 `index.html` 的结束 body 标签前，不放进 `data/resources.json`；详见 README 的“访问统计”。
- 内容归类、双语、交互与文档检查遵循 `AGENTS.md`；弹窗界面与交互见 `doc/more-dialog-design.md`；每个栏目的候选检索、证据与取舍结论记录在 `doc/检索与筛选记录/`（一栏目一文件，含不收清单与待核实清单）。
